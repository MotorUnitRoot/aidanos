# AidanOS design law

Bounce the live slice if a stranger would feel a demo against these. One page. Not comps. Not a theme store.

## Door
Almost empty. The question is a prompt bar: “What do you want to do today?” Get to work opens Today with no question. Empty Enter still skips. No chatbot thread. No nav mall.

## Paper
The daily is the day file. NotePlan muscle, Byword quiet. Real headings, hanging lists, styled checkboxes, more air. Not a textarea dump. Paper is 42rem, centered. Disk stays raw markdown.

## Today
Week cards at the top of the left column; a click opens that day’s paper. Right rail is a Google-style 30-minute day. Drag a line onto a slot; the slot shows a ghost. Month is show/hide, default hidden. Ask or find is a smashable strip; a hit has a file name and opens in the same paper.

## Plan
The season file in human words: title, why, next steps, waiting. Never horse. Never Mark.

## Skin
Stoic tokens: cream on charcoal, one serif, quiet hairline. One `skin.css` in the vault. Skin is color and type, never extra chrome or a changed layout.

## Last-mile
Last-mile UI is generated for the work, as vault files. Not a theme store. Not a settings mall. The user asks; the app changes.

## Disk
The vault is disk. Projects are folders. No second store.
