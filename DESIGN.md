# AidanOS

This page is the look and feel of the product. If a screen disagrees with it, the screen is wrong.

## The door
The first screen is almost empty. It asks one question: “What do you want to do today?” The question looks like a search field, not a floating line of type. A button labeled, "Get to Work" opens the day with nothing typed. The is also a button for, "Capture thoughts," which launches a blank page for writing. Pressing Enter on an empty field does the same. There is no conversation thread here.

## The day’s note
The day’s writing is a real note. It should feel like NotePlan inside the app, and as quiet as Byword: true headings, lists that hang, checkboxes you can tick, and enough space to breathe. Markdown but presented as finished copy. An infinite scroll of history, but somehow not overwhelming. It is not a dump of raw marks. The writing column is 42rem wide and sits in the center. What is saved on disk is ordinary markdown.

## The day
Week cards sit at the top of the left column. Opening a card opens that day’s note, plan, and intention. The right side is a single day, drawn like Google Calendar, month on top, agenda below in half-hour slots. Dragging a line from the note onto a slot places it in time, and the slot shows a preview while you drag. These slots can be extended to fill as much duration as necessary. The month calendar can be shown or hidden. At the bottom is a quiet field for asking or finding. A result has a file name. This search should be more agentic and opinionated that simply call and response. Opening a result uses the same note, not a separate preview.

## The plan
The plan is this season’s file, written in ordinary words: a title, why it matters, what comes next, and what is waiting. It is not a costume, and it is not a second product.

## How it looks
The default skin is Stoic: cream on charcoal, one serif typeface, a quiet line. A person may keep one skin file in their vault. That file may change color and type. It may not add chrome or rearrange the layout. There is no catalog of themes.

## Strucutre
Work is organized into a PARA structure, and x-linked using wikilinks, to support a knowledge graph view. Users can access this view, but the tool manages the organization. The thought here is that this is not a tool for people to organize themselves, it is a tool that organizes thoughts and work to unlock the productivity and creativity of users. 

## Tools for the work
When a task needs a screen, that screen is made for the work and kept as files in the vault. It is not chosen from a shop of themes, and there is no page of settings. You ask, and the app changes.

## Disk
The vault is the disk. Folders are projects. Notes, the day’s file, the season’s plan, and any map of work are files in that vault. There is not a second database.
