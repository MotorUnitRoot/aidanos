# AidanOS design system

DESIGN.md is the law. SYSTEM.md is a short note. This folder is the design system: foundations, a component library, and patterns. Architect (and later last-mile generation) ships from these files. They are vault files, not a Figma file and not a catalog of themes.

Open `components/library.html` and `patterns/` in a browser to see the parts. Tokens live in `foundations/tokens.css`. If a new screen cannot be built from these parts, it does not belong in AidanOS.

The laws that bind this system: the Door stays almost empty; the paper is 42rem and quiet like Byword, with NotePlan muscle; the skin is Stoic; there is no theme catalog, no Salesforce chrome, and no second store.
