# Pressure

Thirteen ordinary surfaces, pressed against this closed library. All pass. No Keep atom was added to make a surface fit. If a surface seemed to need a new control, the answer was compose or refuse.

Keep stays thirty-four. The PR 6 kernel stays Already. Board column and board slip wait with the later pack.

## Mail — PASS

A letter is title, multiline, person chip, place crumb, attachment line, confirm pair. Send is a hairline button. A thread is log activity. Not a toast stack. Not a reaction kit.

## Calendar — PASS

The kernel already has week card, month day, agenda slot, drag preview, and duration mark. A generated hours page uses date, time, and list row. Not a timeline view in v1.

## Notes — PASS

Title, multiline, hanging list, wiki link, quiet label, empty state. The paper is the note. Not a second editor chrome.

## Chat — PASS

Ask strip and search hit already exist. A short exchange is activity lines on paper. Not a floating chat. Not a presence dot.

## Checkout — PASS

Key facts, labeled fields (money, number, date), validation line, confirm pair. A receipt is a quiet sheet. Not a branded pay badge.

## Settings — PASS

Settings group: section head and labeled fields. A binary fact is a checkbox. The operating system file dialog is System; do not skin it. Not a theme catalog.

## Admin tables — PASS

Data table, filter chips row, pagination strip, bulk bar, list row. Previous and Next are text links. Page n of m is a progress fraction. Not a grid chrome.

## Charts — PASS

Refuse a chart zoo. A number is a labeled field or key fact. A register is a data table. Empty is Write. Not a dashboard tile.

## Media — PASS

Refuse a scrub bar and a player kit. Time plus skip and jump hairline buttons, plus duration mark or progress fraction. Attachment line for the file. Not a slider.

## Auth — PASS

Text input, validation line, page message, confirm pair. A signed-in name is a person chip. Not an avatar pile.

## Onboarding — PASS

Empty Door, prompt bar / actions row, empty state, stage steps as words. Not a carousel. Not a FAB.

## File picker — PASS

Lookup field or search field plus search hit, then a wiki link or attachment line. The operating system file dialog is System. Not a Files tab.

## Offline / error — PASS

Page message, soft notice, validation line, spinner/loading, empty state. Saved chip does not shove the paper. Not a toast stack. Not skeleton shimmer.

## Refused kits (still refuse)

Reaction kits. Scrub or slider. Chart zoo. Toasts. Toggles. Badge counts. Avatar piles. Icon-only buttons. Presence dots. Path chevrons. Highlights panels. Utility bars. Console subtabs. App Builder mosaics. FABs. Left icon nav rails. Monday rainbow. Lightning brands. Theme catalogs. Traffic lights.
