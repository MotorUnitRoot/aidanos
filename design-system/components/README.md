# Component library

This is a closed list. Last-mile generation may use only these parts. If a control is not on this list, do not invent it.

Get to Work and Capture thoughts are two uses of the hairline button. They are not two special components. Accept and Reject are the same button. Today, Plan, Month, and close are the text link.

- Door prompt bar
- Hairline button
- Text link
- Week card
- Week chevron
- Day chevron
- 42rem paper
- Checkbox
- Hanging list
- Wiki link
- Quiet label
- Empty state (Write.)
- Ask strip
- Search hit
- Half-hour agenda slot
- Drag preview
- Month day (mark if a note exists)
- Saved chip (reserved space, does not shove the paper)

Each part names the tokens it uses and how it behaves. Open `library.html` to see them. The look lives in `primitives.css`. Patterns load that file. They do not invent a look.
