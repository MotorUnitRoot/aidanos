# Pattern: last-mile

Door, Today, and Plan are the product. When a task needs another screen, that screen is generated only from the component library and written as files in the vault next to the work.

Generation may only emit the named primitives in `components/README.md` and the closed Keep, Already, and Composition names in `atomic-library/TABLE.md`. Get to Work and Capture thoughts are the hairline button. If the work seems to need a new look, a Salesforce field, or a new widget, stop. The system is wrong. The system changes first, or the screen is not shipped.

A last-mile screen assembles those primitives. It does not invent a look. A person can open those files, change them, and delete them. They are not frames in Figma, not a component library dump, and not a Salesforce form.

The letter map is the example. Open `generated.html` to see a generated application assembled only from those parts. `maps/reply-to-a-letter.md` names `[[the-reply]]`. The reply is a markdown file beside the map. Ask may put next steps on today. Nothing about that work lives in a second database.
