# Pattern: last-mile

Door, Today, and Plan are the product. When a task needs another screen, that screen is built only from the component library and written as files in the vault next to the work.

A last-mile screen uses the 42rem paper, the same serif, the same Stoic tokens, hanging lists, checkboxes, and wiki links. A person can open those files, change them, and delete them. They are not frames in Figma, not a component library dump, and not a Salesforce form.

The letter map is the example: `maps/reply-to-a-letter.md` names `[[the-reply]]`. The reply is a markdown file beside the map. Ask may put next steps on today. Nothing about that work lives in a second database.
